## 實際修改

- 依提供 HTML 的天藍、圓角、髮絲紋與細金邊重整四頁；霧天藍主背景 `#c4d5de`，避開素材原本接近白色的亮度。
- 側欄提供霧天藍／深鋼藍切換；共用語意色彩設定涵蓋文字、背景、圖表與商品底色。

- 保留 Dashboard、程式、社群、選品與既有互動；沒有串接 Shopee API、資料庫或後端。
